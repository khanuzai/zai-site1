I wanted a personal site that felt like something — not a template, not a
dashboard. So it looks like a manga page: warm paper, black ink, and
hand-drawn crosshatching inside the panels.

## The shell

The homepage is a single canvas: two panels split by a slanted gutter, a clean
moon left unhatched, soft ink washes, and a small flock of bats that scatter
when you move the cursor. It is plain Canvas 2D — no animation libraries — and
it stops itself if you prefer reduced motion.

## Everything else

Every other page is quiet on purpose: one column, a title, and a single
hand-inked rule. The content lives in files, so writing a new post or adding a
project never means touching a component.
